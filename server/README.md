# Заявки с сайта → MAX (и/или Telegram)

Форма записи отправляет заявку в `api/lead.php` на вашем хостинге. Обработчик:

1. принимает запросы только с адреса вашего сайта;
2. отсекает спам: невидимое поле-ловушка, отправка быстрее 3 секунд, не больше 5 заявок с одного IP в час, 3 с одного телефона в сутки, 200 всего в сутки;
3. проверяет поля (имя, телефон, услуга, согласие на обработку ПДн);
4. **сохраняет заявку на сервере** в `private/leads/ГГГГ-ММ.jsonl` (первичная запись в РФ — ч. 5 ст. 18 152-ФЗ), старше 12 месяцев — удаляет;
5. присылает сообщение в MAX (и/или Telegram):

```
Новая заявка с сайта
Услуга: Ремонт
Имя: Иван
Телефон: +7 (999) 123-45-67
Авто: Kia Rio 2018
Комментарий: стучит подвеска
№ a1b2c3d4 · 13.10.2026 15:04
```

Если мессенджер недоступен, заявка всё равно сохранена, а код ошибки (без данных клиента) пишется в `private/notify-errors.log`.

## Что нужно

- Хостинг в России с **PHP 8+** и расширением curl (есть на Beget, Timeweb, REG.RU по умолчанию), Apache (`.htaccess`).
- Домен с HTTPS (бесплатный сертификат Let's Encrypt включается в панели хостинга).
- Бот MAX: токен из «MAX для бизнеса» → «Чат-боты» → ⋮ → «Настройки». Нужна верификация ООО.
- (Запасной вариант) бот Telegram: создаётся у @BotFather за 2 минуты. Это трансграничная передача ПДн — перед включением нужно уведомление Роскомнадзора и правка политики.

## Установка

1. На компьютере в папке проекта: `python3 tools/package_hosting.py`. Появится `dist/wagner-hosting.zip` с двумя папками: `public_html` и `private`.
2. В файловом менеджере хостинга:
   - содержимое `public_html` → в папку сайта (обычно `~/ваш-домен/public_html`);
   - папку `private` → **на уровень выше**, рядом с `public_html`, а не внутрь неё.
3. В `private` скопируйте `config.sample.php` в `config.php` и заполните:
   - `allowed_origins` — адрес сайта, например `https://wagnermotors.ru`;
   - `salt` и `setup_key` — две разные случайные строки по 32+ символа;
   - `max.token` — токен бота.
4. Напишите боту в MAX `/start` с рабочего телефона (или добавьте бота в рабочую группу).
5. Откройте `https://ваш-домен/api/setup-check.php?key=ВАШ_SETUP_KEY` — страница покажет, отвечает ли бот, и `user_id` / `chat_id` тех, кто ему писал.
6. Впишите их в `max.recipients` в `config.php`, затем откройте ту же страницу с `&test=1` — в MAX должно прийти пробное сообщение.
7. **Удалите `api/setup-check.php` с сервера.**
8. Отправьте тестовую заявку с сайта, убедитесь, что она пришла, и удалите её из `private/leads/`.

## Безопасность

- Токены — только в `private/config.php`, вне папки сайта. Не пересылайте его, не кладите в git.
- Если токен мог утечь — перевыпустите его в «MAX для бизнеса» и обновите `config.php`.
- В `private/` лежат персональные данные клиентов: доступ — только у владельца аккаунта хостинга, включите 2FA в панели хостинга.
